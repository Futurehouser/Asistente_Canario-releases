# Asistente Canario: downloads

Installers for **Asistente Canario**, the assistant app for Gran Canaria (Sin Plomo 95 price at DISA La Pardilla
with weekly advice, and today's events in Gran Canaria).

👉 **[Download the latest version](https://github.com/Futurehouser/Asistente_Canario-releases/releases/latest)**

| Platform | File | Install |
|---|---|---|
| Android 8.0+ | `AsistenteCanario-X.Y.Z.apk` | Open it on your phone (allow "Install unknown apps" if asked). |
| Windows 10/11 | `AsistenteCanario-PC-portable-X.Y.Z.zip` | Unzip it and open `AsistenteCanario\AsistenteCanario.exe`. Nothing to install. |

The app checks this page by itself every time it opens and offers to update when there's a new version.

This repository holds only the published versions; the source code is private.
